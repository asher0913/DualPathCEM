# Snapshot policy

This repository is a frozen public showcase assembled on 2026-09-19 from the
last internally audited stable implementation snapshot.

It intentionally excludes:

- the active private collaboration history;
- manuscript source and reviewer or supervisor comments;
- unfinished post-review experiments;
- private model checkpoints and server state;
- FaceScrub images and reconstructed faces;
- personal, institutional, and collaborator identifiers.

No automatic synchronisation exists between this repository and the private
research repository. Later experiments should not be inferred from this
snapshot, and this public branch is not used as a collaboration remote.
